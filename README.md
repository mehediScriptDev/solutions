# solutions

Basic problem solving with typescript.

## Contents

- `blog-1.md` — First blog draft
- `blog-2.md` — Second blog draft
- `solutions.ts` — TypeScript file with solutions

## Requirements

- Node.js (recommended v14+)
- Optional: `ts-node` and `typescript` if you want to run `.ts` files directly

## Usage

To run `solutions.ts` directly (requires `ts-node`):

```bash
npm install -g ts-node typescript
ts-node solutions.ts
```

Or compile then run with Node.js:

```bash
npx tsc solutions.ts --outFile solutions.js
node solutions.js
```
